# Community cheat sheets

FDL cheat sheets written by the BMW coding community. Each file is named after its author. They're
included unchanged so every OpenLauncher install starts with the same names: the build imports them like
any contributed `<FDL>` sheet (each entry is checked against your psdzdata, and BMW names in the comments
become function and value names).

- **Source:**
  - [packetpilot/bmw-f](https://github.com/packetpilot/bmw-f), `cheats` folder
  - [alexpeterson91/bmw-f](https://github.com/alexpeterson91/bmw-f) (`Cryptocar.xml`)
  - [siegester03/bmw-f](https://github.com/siegester03/bmw-f) (`SergeAA.xml`)
- **Licence:** GNU General Public License v3.0, as declared by those projects ([LICENSE](LICENSE)). This
  folder stays GPL-3.0. The rest of the repo's names (`names\`) are CC0 and don't include these sheets.
- **Not tested by Open CAFD Map.** Check every change before you code a car.
- **Corrections:** put a fixed name in `names\<ECU>.tsv`. Names files always win over cheat sheets.
