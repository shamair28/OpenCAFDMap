# names/versioned

Community names that hold only for some versions of a CAFD: a group rebuilt in a new main version, a function or
bit that changed meaning. Same columns as `names\<ECU>.tsv` plus a 9th, **versions** (`062-`, `-052`, `052-061`,
`062_010_106`, comma-separated ranges). One file per ECU, like the folder above.

For the versions it covers, a row here beats an every-version row in `names\`. Format, examples and rules:
[CONTRIBUTING.md](../../CONTRIBUTING.md#names-for-some-cafd-versions-only). Licence: CC0, like `names\`.
